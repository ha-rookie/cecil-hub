AI駆動開発 実践記録

AIとアプリを作るたびに、
開発のやり方そのものが
変わっていった。

複数のWebアプリをAIと作りながら、失敗をルールに変え、設計やテンプレートへ残してきた。これは、今も更新を続けているAI駆動開発の実践記録です。

PROJECT → FAILURE / LEARNING → RULE → TEMPLATE → NEXT PROJECT

SAMPLE CONTENT

ここから先は、まだサンプル。

今回はキービジュアル、タイトル、共通ヘッダー／フッターの見え方を確認するためのテストページです。

01

思いつく

小さな違和感やアイデアから、何を作るのか、何を作らないのかを整理する。

02

確かめる

実装しただけで終わらせず、CI、Preview、Human Review、本番確認まで証拠を残す。

03

育てる

失敗や改善をルールとTemplateへ戻し、次のProjectで同じところから始めない。
