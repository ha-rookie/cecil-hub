Privacy

This page explains what access data this site handles and how that data is used.

Updated: September 22, 2026
01

What this site measures

This site uses Cloudflare Workers Analytics Engine for anonymous analytics to understand how visitors arrive and which links they follow from the site.

For page views and outbound clicks, the site records items such as traffic source, referrer hostname, page path, and destination category.

02

Data this site does not store

The site’s own Analytics Engine dataset does not store the following information.

  • IP address
  • User-Agent
  • Cookie ID
  • User IDs stored in localStorage
  • Browser fingerprints
  • Name or email address
  • Full referrer URL

The site’s own analytics does not use cookies or identifiers to identify individual visitors.

03

Purpose

Aggregated data is used to understand where visitors come from and which content they move on to, helping improve navigation and what is presented on the site.

04

Data retention

According to Cloudflare’s official documentation, data written to Workers Analytics Engine is retained for three months.

View Cloudflare documentation

05

About Cloudflare

This site is delivered using Cloudflare infrastructure, so network traffic passes through Cloudflare services. The “Data this site does not store” section above refers specifically to the analytics data this site writes to Workers Analytics Engine.
